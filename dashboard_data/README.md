# Dashboard Data Directory

This directory contains all the source data files required by the NEMAR Dataset Citations Dashboard. These files are generated by various analysis pipelines and must be kept up-to-date for the dashboard to display accurate information.

## 📁 Directory Structure

```
dashboard_data/
├── network/                    # Network analysis results
│   ├── dataset_popularity.csv       # Dataset citation counts & rankings
│   ├── citation_impact_rankings.csv # Top cited papers (MUST have 20+ entries)
│   ├── dataset_co_citations.csv     # Dataset co-citation relationships
│   ├── multi_dataset_citations.csv  # Papers citing multiple datasets
│   ├── bridge_papers.csv            # Research bridge papers
│   └── author_influence.csv         # Author influence metrics
├── temporal/                   # Temporal analysis results
│   └── temporal_summary.csv         # Citation growth over time
├── themes/                     # Theme analysis results
│   └── comprehensive_theme_analysis.json  # Research themes & clusters
└── README.md                   # This file
```

## 🔄 Update Process

### Quick Update (Recommended)
```bash
# Update all dashboard source files with proper parameters
python scripts/update_dashboard_data.py \
  --dashboard-data-dir dashboard_data \
  --citations-dir citations/json \
  --neo4j-password YOUR_PASSWORD
```

### Verify Dependencies
```bash
# Check if all required files exist and are valid
python scripts/update_dashboard_data.py --verify-only
```

### Manual Update (If needed)
If the automated script fails, you can update individual components:

1. **Network Analysis** (Most Important)
```bash
dataset-citations-analyze-networks \
  --neo4j-uri bolt://localhost:7687 \
  --neo4j-user neo4j \
  --neo4j-password YOUR_PASSWORD \
  --output-dir dashboard_data/network \
  --limit-results 25  # Important: Get top 25 citations for dashboard
```

2. **Temporal Analysis**
```bash
dataset-citations-analyze-temporal \
  --citations-dir citations/json \
  --output-dir dashboard_data/temporal
```

3. **Theme Analysis**
```bash
dataset-citations-analyze-themes \
  --embeddings-dir embeddings \
  --output-dir dashboard_data/themes
```

## ⚠️ Critical Requirements

### Citation Impact Rankings
The `network/citation_impact_rankings.csv` file **MUST** contain at least 20 entries for the dashboard citation modal to work properly. The default analysis only generates 5 entries, which is insufficient.

**Required columns:**
- `citation_title`: Paper title
- `citation_author`: Authors
- `citation_year`: Publication year
- `venue`: Publication venue
- `citation_impact`: Number of citations (cited_by count)
- `confidence_score`: Confidence score (≥0.4 for inclusion)
- `dataset_id`: Associated dataset ID
- `dataset_name`: Dataset name
- `dataset_total_citations`: Total citations for the dataset

### Dataset Popularity
The `network/dataset_popularity.csv` file should include ALL datasets (302+) with their high-confidence citation counts.

**Required columns:**
- `dataset_id`: Dataset identifier
- `dataset_name`: Dataset name
- `high_confidence_citations`: Count of citations with confidence ≥0.4
- `total_citations`: Total citation count (for reference)

## 🎯 Dashboard Generation

After updating the source files, generate the dashboard:

```bash
# Generate NEMAR dashboard with updated data
python -c "
from dataset_citations.dashboard.core import DashboardGenerator
from pathlib import Path

gen = DashboardGenerator(
    results_dir=Path('dashboard_data'),
    output_dir=Path('interactive_reports'),
    citations_dir=Path('citations/json')  # Important: Must specify this!
)

output_path = gen.generate_dashboard(dashboard_type='nemar', lazy_load=True)
print(f'Dashboard generated: {output_path}')
"
```

## 🔍 Validation Checklist

Before generating the dashboard, ensure:

- [ ] `citation_impact_rankings.csv` has 20+ entries
- [ ] `dataset_popularity.csv` includes all 302 datasets
- [ ] `bridge_papers.csv` is present
- [ ] `citations/json/` directory contains all citation JSON files
- [ ] All CSV files have proper column headers
- [ ] Confidence threshold is consistently 0.4 across all files

## 🐛 Troubleshooting

### Problem: Citation modal only shows 5 papers
**Solution:** Re-run network analysis with `--limit-results 25` parameter

### Problem: Dashboard shows 0 citations
**Solution:** Ensure `citations_dir` parameter is passed to DashboardGenerator

### Problem: Dataset network shows wrong citation counts
**Solution:** Verify that dataset_popularity.csv uses high_confidence_citations column

### Problem: Missing data files
**Solution:** Run the update script: `python scripts/update_dashboard_data.py`
